## 🚀 เริ่มใช้งาน

รันตัวเลือกสคริปต์ตัวเดียว แล้วเลือกโปรไฟล์ที่ต้องการจากเมนู:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Petch25-1/PlayerHUB/refs/heads/main/Player_universe.lua"))()
```

## 📦 สคริปต์ทั้งหมด

| สคริปต์ | คำอธิบาย |
|---|---|
| 🧭 **Player_universe** | หน้าต่างเลือกสคริปต์ (Selector) เลื่อนดูรายการได้ กดเลือกแล้วโหลดให้ทันที |
| ⚡ **PlayerHUB** | สคริปต์ศูนย์กลางหลัก มีแท็บ Stats / Player / Visuals / World / Camera / Settings |
| 🧟 **Route06** | โปรไฟล์เฉพาะแมพ Route 06 (CFrame Speed, Kill Aura, Mob Lock & Bring, Fullbright, Weather Remover, ESP) |
| 🔪 **MM2** | โปรไฟล์เกม MM2 |
| ⚒️ **Dumper** | เครื่องมือเสริม Dumper |

<details>
<summary>📋 ลิงก์โหลดแต่ละตัวโดยตรง</summary>

## ✨ จุดเด่น

- 🎨 UI ธีมม่วง–ฟ้า ลากย้ายหน้าต่างได้ ปรับขนาดได้ (UI Size Scale)
- 🔍 ช่องค้นหาฟังก์ชันด้านบนเมนู
- 🟣 แผง **Active Features** ดูว่าเปิดฟีเจอร์อะไรอยู่ และกดปิดทั้งหมดได้ในที่เดียว
- 🔔 แจ้งเตือนแบบ Toast ตอนเปิด/ปิดแต่ละฟีเจอร์
- ✨ หน้าโหลดแอนิเมชัน (อนุภาคลอย, วงแหวนหมุน, แถบโหลดมีประกาย)
- 📊 แท็บ Stats แสดง FPS, Ping, Memory, HP และพิกัดแบบเรียลไทม์
- 🛡️ แต่ละส่วนโหลดแยกกัน ถ้าส่วนใดพัง ส่วนอื่นยังทำงานต่อได้
